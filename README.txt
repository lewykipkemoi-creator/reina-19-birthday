# Reina Turns 19 💜

A playful, interactive birthday website made for Reina by Lewy.

## Files
- `index.html` — page structure/content
- `style.css` — all styling and responsive design
- `script.js` — surprises, quiz, confetti, modal, and runaway button
- `assets/reina-portrait.jpg` — uploaded portrait
- `assets/reina-flowers.jpg` — uploaded flowers photo

## Run it
Keep the folder structure intact and open `index.html` in a browser.

No server or build step is required.
